# 图形组组内的学习方案

这部分是组内成员都要求完成的（硬性规定），这也是仓库名里 **"unified"** 的意思。

当然不是一上来就要学 games 课程什么的，其实是等大家跟着程序大组把 OOP 熟悉一遍之后（训练出一点编码的感觉），再上点强度学习正经的图形知识。

具体的计划见飞书上的招新文档：[图形方向招新文档](https://thinkdifferent-club.feishu.cn/wiki/UTOdwugsNiVXtckjt5CcmK8pn7b?from=from_copylink) 的 “组内预定路径” 部分。
