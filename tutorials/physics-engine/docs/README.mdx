## 为什么游戏需要物理引擎
在游戏中物理引擎其实是可有可无的，这取决于你的游戏是否需要实现物理效果，对于我们常玩的 2D 游戏，如：[プロジェクトセカイ カラフルステージ！ feat. 初音ミク（pjsk）](https://pjsekai.sega.jp/)、[植物大战僵尸](https://www.ea.com/ea-studios/popcap/plants-vs-zombies)、[サノバウィッチ（魔女的夜宴）](https://www.yuzu-soft.com/new/product/sothewitch/)等等是不需要使用到物理引擎的呀！即使是 [Minecraft](https://www.minecraft.net/) 这种 3D 游戏也不会用到物理引擎 ~所以就会出现悬浮的沙块这种现象~ ~

但是在大多数 3D 游戏中，如下这些人类史上出色的游戏都需要使用游戏物理引擎提供的物理效果。
### [Half-Life: Alyx](https://store.steampowered.com/app/546560/HalfLife_Alyx/)
![Half-Life:Alyx](/assets/tutorials/physics-engine/README/half-life-alyx.jpg)
Half-Life: Alyx 是一款 VR 游戏，在 VR 游戏中物理引擎尤为重要，因为相比平面游戏， VR 带来的真实感是无与伦比的。正是因为 VR 带来的极强的真实感，如果物理引擎不能提供符合直觉的惯性、重量感和碰撞反馈，大脑就会感到矛盾，让玩家感到晕动症。如果没有物理引擎实时计算碰撞、摩擦、重力，你的手会直接穿模，或者杯子像焊死在桌上一样纹丝不动，沉浸感瞬间归零。

### [Portal 2](https://store.steampowered.com/app/620/Portal_2/)
![Portal2](/assets/tutorials/physics-engine/README/portal.jpg)
Portal 2 是一款基于物理的但超越现实世界物理的解密游戏 ~没错学习计算机图形学你可以成为创始者，在虚拟世界中制定非现实的物理定律~，在游戏中玩家可以通过 传送门 进行空间穿梭，轻松到达一些难以直接到达的位置，传送门能保持在穿过传送门时动量守恒。除此之外，玩家需要利用基于物理的方块、激光等激光进行解密。

### [塞尔达传说：王国之泪](https://www.nintendo.com/jp/character/zelda/index.html)
![Portal2](/assets/tutorials/physics-engine/README/zelda.jpg)
塞尔达传说：王国之泪是一款沙盒大世界探索游戏，这一版塞尔达相比于前代提供了自由度非常高的基于物理的创造搭建玩法，可以抓取、拼接几乎任何物体，并安装风扇等内容，可以造船、造车、造飞机。而没有物理引擎这是无法做到的。

## 你能学到什么
在这里目前（未来不知道会不会开更新的 3D 内容，看 Artichoke 有没有时间）我们打算教授基本的 **2D 刚体游戏物理引擎**的原理，以及简单的 **2D 流体模拟**。由于 Artichoke 也不是这个领域的专家，所以并不能带你实现一个能媲美顶尖物理引擎最先进最成功的引擎，不过你依然能在这学到物理引擎的基本原理，如果你继续深造则需要自己去探索了，我们的任务是领你进门。  

具体的你能学到的内容（暂定，随时调整）:   
我们将以构建一个项目的形式开始我们的教程，这样最后你们也能得到一个自己的物理引擎。  
我们的教程代码将同步到：https://github.com/TDS-Graphics/simple_physics_engine.git  
2D 刚体游戏物理引擎：

1. 数值积分（Numerical Integration）
- 隐式欧拉
- Verlet 
- 固定时间步长与子步进

2. 碰撞检测（Collision Detection）
- AABB
- SAT（分离轴定理）
- GJK、EPA
- 宽相位与窄相位

3. 接触生成（Contact Generation）
- 接触点与接触法线
- Reference Face / Incident Edge
- Polygon Clipping
- 接触流形（Contact Manifold）
- 接触点穿透深度

4. 约束求解（Constraint Solver）
