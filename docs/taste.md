# 为什么要学原理
吹哥（Jonathan Blow）曾在 DevGamm 2019 的一场名为《阻止文明崩塌》的演讲上指出软件行业正处于一种“技术知识正在流失”的状态。大概意思是现代软件的抽象层太厚，导致很多新一代程序员只会在高度封装的抽象层之上拼装代码，少有人知道底层究竟发生了什么事情。

人类曾在 1969 年实现了登月的壮举（阿波罗计划），然而技术断代导致了今天我们不得不重新研究如何登月。阿波罗计划依赖的是一整代人高度集中的默会工艺与极限工程经验，而这些知识随着项目终止、供应链解散和工程师离世而流失。图纸虽在，但知道怎么做的人已经没有了。

阿波罗计划的那一代人，是从零亲手造出计算和航天的一代。他们之后，我们进入了继承时代。软件行业也是一样，开天辟地的时代已经过去了，现在是继承的时代。继承时代最大的问题是：**如果继承的东西坏了，而你已经看不懂它是怎么造的了，你该怎么办？**

幸运的是，在电脑面前开发需要承担的代价比登月要小一点，所以我们有机会作出一点补救。所以这就是 TDSG 想对大家说的：**学原理吧！理解事情是如何运作的；动手吧！看看真实系统的运转，最好是能做出来。**
