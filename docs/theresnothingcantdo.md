# 没有什么不能做到了
目前我们正在经历一个剧变，一个混沌的转型期，旧的思想尚未清除，新的方法仍在探索，我们就处在这样一个技术时代。

## 不要畏手畏脚
截止本文发布日期，你能搜寻到的经典课程都是 Pre-LLM 时代的，包括很多顶级学校的课（就拿图形学来说，经典的 GAMES101 其实就是闫令琪老师当年在 UCSB 开的 CS180 图形学课，只是课程编号不一样）。

GAMES101 的作业在以往需要耗费巨大的精力配置 IDE、CMake 和 Eigen, OpenCV 等环境，单单是这一关就卡了一大半想要做图形学实践的人。但是，如今你只需要一句话 Agent 就能在几分钟内解决，你可以直接地专注于图形学算法，**入门的门槛彻底被降到了 0**。

这只是从 GAMES101 项目环境配置的层面。事实上，你整门课的全部 assignment 都可以直接扔给 AI 做完，然后让它逐行代码给你讲解，你大概在很短时间内就能掌握现代图形学的核心思想，然后就是 202, 104 这类更加进阶的内容......最后，你就具备了足够的基础了。虽然以前的人也是这样一条路下来，但他们是磕磕碰碰，这中间有不计其数的人放弃，而我们现在是顺风顺水，只要想就能上。

## 打出差异化
这是最好的时代，也是最坏的时代。刚刚提到我们现在的现状是：**只要想就能上。这意味着试验成本降到了 0，这种好事当然是个人都想去尝试**，于是你就看到——例如——b站首页给你推的一大堆复刻某些二游的渲染、一大堆模板化的作品集，有些视频你甚至都不用点进去就能猜到是什么内容（我列几个吧，无非就是 industry 已经实现了几万遍了的什么什么风格的人物渲染、草地、程序化地形、水面或类似），**一个稍微有品味的人都会感到审美疲劳。**

如果说在 2025 年之前，这些东西还能体现你有一定的代码迁移能力或者模仿能力，那现在这种能力就是真的一分钱不值了。我们都不说未来一年，就说现在。Agent 最擅长的就是迁移和模仿。人类需要保留的是品味和判断力，它们其实就来自于对基本原理的学习探索和掌握，而不是来自于生搬硬造的模仿。

**如果你还觉得现在复刻一个实现过几万次了的东西还有市场价值，趁早打消这个念头，因为这一点太容易被想到和实现了。** 并且最重要的是，这很无聊。我们一切的一切都是 just for fun。

除非你并不考虑找工作，加上本身对造轮子有狂热的兴趣，享受自己打造每一个细节的快感，这种人就好像纯粹的游戏玩家，玩游戏只为开心，这无疑是件好事。

但是，**如果你一心想打职业，那么你真得认真想想这个问题了。**
