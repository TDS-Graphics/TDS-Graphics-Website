# 学习路线总览

## 第零阶段
**通过本阶段的学习，你将可以：**
  1. 分析基本的游戏图形技术。
  2. 了解哪些图形技术会很吃资源，并能更聪明地调节游戏画质设置。
  3. 对游戏图形的发展有基本的感觉。

> **这个阶段在开始约两周后就会和第一阶段重叠。并且，本阶段不会有明显的结束时间，** 因为这个阶段的核心内容是需要长期观看的。

在第零阶段，主要是让大家去**看一些高质量的图形学科普视频**，并且结合里面的一些技术名词分析自己喜欢玩的游戏利用了什么技术，**从顶层**（最终效果层面）**先建立起一个对游戏图形技术的感觉**。
  
看完那些视频只用花两周的时间，但是把素质培养起来是个漫长的过程，在这个阶段之后也需要随时关心一些优质的图形学内容。

第零阶段的具体内容页在此：[**阶段 0 | TDS Graphics**](../tutorials/stage0)
  
## 第一阶段
**通过本阶段的学习，你将可以：**
  1. 大脑升级，，，
  2. 能看懂技术文章里的数学公式想表达什么
  3. 高数线代挂科的概率降低很多
  4. 学会使用 Git, Shell, Agent 等主流工具
  5. 学会构建、调试和修改 C++ 项目
   
> **这是一个大阶段，对大一刚来的新生而言需要一个学期的时间。**
   
### 图形学与游戏开发的数学基础
过了第零阶段，就需要学习一些基本的数学知识，它们将成为理解游戏图形的基础。

放心！！我们只要求能看懂符号表达式的含义，而不是让你刷题。

  - **常用数学**
    - **线性代数**
    - **微积分（高等数学）**
    - 概率论
  - 拓展知识
    - 群、环、域
    - 流形与微分几何
    - 微分方程、积分方程
    - 算子理论、无穷维线性代数

常用数学是必学的，直接联系到第一阶段的过关问题。**我们只要求线代和微积分过关。概率论其实属于选修**，因为我们不会一上来就研究路径追踪，可以暂时放一放，后期会简要介绍概率论。

拓展知识方面，我们会在一些内容提及这些更高级的数学在图形学或其它领域的体现，感兴趣的朋友可以了解一下~

第一阶段的具体内容页在此：[**阶段 1 | TDS Graphics**](../tutorials/stage1)

### 基本工具链和 C++ 编程语言

你要学会如何用 Git, Shell 和 Agent，这些是必备的生产工具，无论做哪门计算机技术都需要，不只是图形/游戏。

C++ 是一门多范式的高性能编程语言，常用于渲染器和游戏引擎开发。在进入第二阶段真正的图形学之前，需要一些 C++ 基础。
  
## 第二阶段
  **通过本阶段的学习，你将可以：**
  1. 理解并实现主流图形学算法。
  2. 自上而下地对整个领域有清晰的认识。
  3. 能够精确地描述图形技术细节，并据此写出具体实现或具有合理约束的 Prompt。

 > **这个阶段将正式学习图形渲染，也是一个大阶段。学习周期也是预计一学期。**
  
  第二阶段又会分为两个子阶段——**正式入门**阶段和**专题探索**阶段：
  
### 正式入门阶段
  开始系统地学习基础的图形学，例如 **光栅化（Rasterization）** 和 **光线追踪（Ray Tracing）** 算法以及它们的实现；渲染管线的基本机制和实现；以及一些重要的根基性理论，例如 **全局光照（Global Illumination）** 、**材质表面建模（Appearance Modeling）** 等。

  首先，我们不会遵循传统路径——也就是绝大多数计算机图形学课程的先光栅化再光追，相反地，我们是先光追再光栅化。这其中有多方面的考量，会在 GitHub /  TDSG 官方网站 里详细的图形文档里说明，或者在 QQ 群里聊到。

  **暂定的正式入门阶段的训练方式是**：**主线**——完成为大家设计的 project + 按照我们指定的顺序观看 GAMES101；**支线**——快速浏览犹他大学的 CS4600 Intro to Computer Graphics 课程、阅读 Fundamentals of Computer Graphics（第四版或第五版）。
  
### 专题探索阶段
  继续拓展深度，例如上个阶段一笔带过的实时阴影方法，在这里就会直接要求学习并实现。
  具体规划的内容包括：
  - **高质量实时阴影**

  - **全局光照**
  
  - **PBR 渲染**
  
  - **生产级光线追踪**

  - **风格化渲染（NPR）**

出于难度时间精力等因素的考量，我们将会从以上内容里选取最基础最重要的一部分作详细要求，并设计教程 project 等。

但是**个人的自由探索学习是被鼓励的，自由探索内容不设限。**
  
专题探索阶段的主线是很自由的，你可以选择在 101 的基础上继续看 [**GAMES202 - 高质量实时渲染**](https://www.bilibili.com/video/BV1YK4y1T7yY/) 课程，并完成 202 为大家提供的作业，它涵盖了专题探索阶段里的很多主题。当然，你也可以选择参考本文档给出的专题并配合我们自己的技术视频/文章/项目，立刻投身于自己的实践。对于很大一部分人来说，我推荐做项目，因为从实践中学习是最快的，但这也不是没有代价，这种做法会欠基础债。

如果对你本人而言，看课的帮助更大或者更安心，想先建立起结构化的认知基础，那么就看课——**但是别不做作业！哪怕是 ai 给答案你自己手敲进 IDE 跑一遍也比只看课好十万倍！**
  
**总之，找一条你认为最舒服的路去走，每个人的体质不一样。无论选哪条路，到第二阶段结束，你都一定要对现代实时渲染技术的理论和实现有相当程度的认识。**
  
第二阶段结束之时会组织一个自愿参加的项目展（TDSG Showcase），参考[**加州大学伯克利分校的 CS184/284A 图形学课程**](https://cs184.eecs.berkeley.edu/su26/project/)，这里面的东西真的超棒超好玩的！
