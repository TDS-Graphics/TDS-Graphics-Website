在光线追踪算法中，我们通常需要表述光线从相机到光源或者从光源到相机的过程之中击中了什么材质，或者换句话说，我们需要知道路径顶点的材质是什么。比如从光源出发 -> 击中漫反射材质 -> 理想镜面材质 -> 相机。

而这种样式的描述对于科研人员来说有点太过于繁琐，所以 [Heckbert 1990.][^1] 给出了一种符号记号，叫做 **光路正则表达式** (Light path regular expressions) 或者 **Heckbert 路径正则表达式** (Heckbert's path regular expressions)，并且 [Eric Veach 1997.][^2] 在其文章中扩展了 Heckbert 的表示方式，给出了更完整的 **全路径正则表达式** ，并且广泛应用于描述 Bidirectional Path Tracing 、Metropolis Light Transport 等技术的采样策论中。

我们的文章主要围绕着 Eric Veach 的文章简单介绍一下这种表述方式，以便于我们今后使用。所以这篇文章会非常的简单，纯介绍性的，和 Artichoke 写的大部分文章不一样，不要害怕 >3<。

## 光路表达式
需要注意的是，一个物体可能包含的材质是多种混合的，我们现实世界中的物体也不是由单一材质构成的，所以光路表达式并不是想上面举得例子一样是表示击中的材质，而是描述**顶点处发生的散射事件**。

比如 发出光源 -> 发生漫反射 -> 发生理想镜面反射 -> 发生理想折射 -> 发生漫反射 -> 光源被采集。

用我们即将学的光路表达式写就是：LDSSDE.

这很简单对吧！有些对英文敏感的小机灵鬼已经能从符号中猜出来其中的含义了。

| 符号 | 英文 | 含义 |
|-------|-------|-------|
| L | Light | 路径的第一个顶点，位于自发光表面上 |
| E | Eye/Camera | 路径的最后一个顶点，位于传感器/镜头上 |
| D | Diffuse | BSDF 为有限值（$f_s < \infty$）的散射事件，包含 Lambert 反射及普通微表面高光    |
| S | Specular | BSDF 包含奇异性（$f_s = \infty$）的散射事件，如理想镜面反射、理想折射、纯一维拉丝各向异性散射 |

让我们做一些练习熟悉一下这种表达吧！
- 最简单的 LE. 直接表达光源到相机。
- 也很简单的 LDE. 光从光源发出经过一次 Diffuse 再到相机。
- 看个稍微没前面简单的 LSDE. 光从光源出发经过理想折射（玻璃）到 经过漫反射（地面）出现 Caustics 现象最后到相机。

当然有时候我们需要表达这种形式的路径: LDDDDDDDDDDE 。光在漫反射场景中经过 n 次弹射到达相机，我们不可能每次都写 n 遍符号吧！所以懒惰的科学家们又发明出了一些符号用于简化。


| 符号 | 含义 | 示例/解释 |
|-------|-------|-------|
| `*`    | 重复 0 次或任意多次 | `D*`：经过 0 次或多次漫反射 |
| `+`    | 重复 1 次或任意多次 | `S+`：经过 1 次或多次理想镜面反射 |
| `?`    | 重复 0 次或 1 次    | `S?`：最多经过 1 次镜面顶点（有或没有都行） |
| `(..)` | 分组                | `(DS+)`：把 DS+ 当作一个整体重复 0 次或多次 |
| `\|`   | 或                  | `(S\|D)`：该顶点可以是 S，也可以是 D |

再让我们做一些练习熟悉一下这种表达吧！
- LD*E 纯漫反射场景。
- LS+DE 经过多个理想镜面反射，或者理想折射产生 Caustics.
- LDS+E 透过玻璃看到的漫反射物体
- L(S|D)*E 场景中的全部光路。  

### 全路径正则表达式
在 [Eric Veach 1997. 8.3.2. ][^2] 中给出了 全路径正则表达式 ，在 [Heckbert 1990.][^1] 的基础上描述光源和传感器的属性。

对于光源 L 后面紧跟着的两个符号 `(S|D)(S|D)` 表示为光源的 **面积属性** 和 **方向属性**。
对于传感器 E 前面紧跟着的两个符号 `(S|D)(S|D)` 表示传感器对 **方向的敏感性** 和传感器的 **面积属性**。

具体的
- 对于光源
  - 第一个字母中 D 表示有限面积光源，即面积 $0 < A < \infty$（如面光源、球光源等等），S 表示零面积光源 $A = 0$（如点光源等等）。
  - 第二个字母中 D 表示在有限立体角度，即立体角 $0 < \sigma(\omega) < \infty$ (如点光源，球面光等等)，S 表示零立体角 $\sigma(\omega) = 0$ (如 Directional Light 等等)。
- 对于传感器
  - 第一个中 D 表示对有限立体角内的入射光敏感，即立体角 $0 < \sigma(\omega) < \infty$（如有限孔径镜头）；S 表示只对测度为零的方向集合敏感，即零立体角 $\sigma(\omega) = 0$（如针孔镜头、理想化的点式辐射计）。
  - 第二个中 D 表示有限面积传感器 $0 < A < \infty$；S 表示零面积传感器 $A = 0$。

> 需要注意的是：光源的两个字母顺序是 **先面积、后方向**，而传感器的两个字母顺序是 **先方向、后面积**。

按照这个约定，Veach 在表 8.1 中列出了一些真实光源和传感器的表示：

| 类别 | 正则表达式 | 含义 |
|------|------------|------|
| 光源 | `LDD` | 漫反射发光球体 |
| 光源 | `LDS` | 阳光穿过窗户，其中窗户本身被建模为光源 |
| 光源 | `LSD` | 点光源 |
| 光源 | `LSS` | 激光束 |
| 传感器 | `DDE` | 有限孔径镜头 |
| 传感器 | `SDE` | 正交投影镜头（其中图像平面位于场景内，而不是在无穷远处） |
| 传感器 | `DSE` | 针孔镜头（能接收有限立体角内的光，但孔径面积为零） |
| 传感器 | `SSE` | 理想化的点式辐射计（沿给定单条光线测量辐射亮度） |

- `LDD` 是「有限面积 + 朝所有方向发光」的普通面光源（发光球体），`LDS` 是被建模为光源的窗户，方向单一，`LSD` 是面积为零但向四面八方辐射的点光源，`LSS` 则是面积为零、只沿单一方向发射的激光束。
- `DDE` 是「对有限立体角敏感 + 有限感光面积」的有限孔径镜头，`DSE` 是「对有限立体角敏感 + 面积为零」的针孔镜头，`SDE` 是「只收集单一方向的光 + 有限感光面积」的正交投影镜头，`SSE` 则退化成沿一条光线测量辐射亮度的理想点式辐射计。

综上所有的符号，我们可以写出如下的表达式：
- LDDS*DDE 表示它始于一个普通的面光源，被零个或多个镜面散射，并终止于一个普通的有限孔径镜头。
- LSDSDSE 点光源经镜面反射，通过针孔镜头观察。
- LDSSDSDE 来自平行光源的焦散，通过正交镜头观察
- LSDSDSDSE 来自点光源的焦散，通过针孔镜头经镜子间接观察
- LDD(S|D)\*DD(S|D)\*DDE 通用双向路径追踪 BDPT 在常规相机/面光源下的可采样路径，即包含 DD 子串

### 全路径正则表达式
在 [Eric Veach 1997. 8.3.2. ][^2] 中给出了 全路径正则表达式 ，在 [Heckbert 1990.][^1] 的基础上描述光源和传感器的属性。

对于光源 L 后面紧跟着的两个符号 `(S|D)(S|D)` 表示为光源的 **面积属性** 和 **方向属性**。
对于传感器 E 前面紧跟着的两个符号 `(S|D)(S|D)` 表示传感器对 **方向的敏感性** 和传感器的 **面积属性**。

具体的
- 对于光源
  - 第一个字母中 D 表示有限面积光源，即面积 $0 < A < \infty$（如面光源、球光源等等），S 表示零面积光源 $A = 0$（如点光源等等）。
  - 第二个字母中 D 表示在有限立体角度，即立体角 $0 < \sigma(\omega) < \infty$ (如点光源，球面光等等)，S 表示零立体角 $\sigma(\omega) = 0$ (如 Directional Light 等等)。
- 对于传感器
  - 第一个中 D 表示对有限立体角内的入射光敏感，即立体角 $0 < \sigma(\omega) < \infty$（如有限孔径镜头）；S 表示只对测度为零的方向集合敏感，即零立体角 $\sigma(\omega) = 0$（如针孔镜头、理想化的点式辐射计）。
  - 第二个中 D 表示有限面积传感器 $0 < A < \infty$；S 表示零面积传感器 $A = 0$。

> 需要注意的是：光源的两个字母顺序是 **先面积、后方向**，而传感器的两个字母顺序是 **先方向、后面积**。

按照这个约定，Veach 在表 8.1 中列出了一些真实光源和传感器的表示：

| 类别 | 正则表达式 | 含义 |
|------|------------|------|
| 光源 | `LDD` | 漫反射发光球体 |
| 光源 | `LDS` | 阳光穿过窗户，其中窗户本身被建模为光源 |
| 光源 | `LSD` | 点光源 |
| 光源 | `LSS` | 激光束 |
| 传感器 | `DDE` | 有限孔径镜头 |
| 传感器 | `SDE` | 正交投影镜头（其中图像平面位于场景内，而不是在无穷远处） |
| 传感器 | `DSE` | 针孔镜头（能接收有限立体角内的光，但孔径面积为零） |
| 传感器 | `SSE` | 理想化的点式辐射计（沿给定单条光线测量辐射亮度） |

- `LDD` 是「有限面积 + 朝所有方向发光」的普通面光源（发光球体），`LDS` 是被建模为光源的窗户，方向单一，`LSD` 是面积为零但向四面八方辐射的点光源，`LSS` 则是面积为零、只沿单一方向发射的激光束。
- `DDE` 是「对有限立体角敏感 + 有限感光面积」的有限孔径镜头，`DSE` 是「对有限立体角敏感 + 面积为零」的针孔镜头，`SDE` 是「只收集单一方向的光 + 有限感光面积」的正交投影镜头，`SSE` 则退化成沿一条光线测量辐射亮度的理想点式辐射计。

综上所有的符号，我们可以写出如下的表达式：
- LDDS*DDE 表示它始于一个普通的面光源，被零个或多个镜面散射，并终止于一个普通的有限孔径镜头。
- LSDSDSE 点光源经镜面反射，通过针孔镜头观察。
- LDSSDSDE 来自平行光源的焦散，通过正交镜头观察
- LSDSDSDSE 来自点光源的焦散，通过针孔镜头经镜子间接观察
- LDD(S|D)\*DD(S|D)\*DDE 通用双向路径追踪 BDPT 在常规相机/面光源下的可采样路径，即包含 DD 子串
